No copyrighted material

Retro Scene Rebuild does not host, distribute or link to games, ROMs, disc images, BIOS files, firmware, keys or any other copyrighted program data.

Each .rsr file holds only:

  • instructions for re-packing files the user already has (archiver, version, switches, volume sizes, file dates);
  • checksums and sizes used to confirm a rebuild is correct;
  • small difference data for archive structure;
  • the release's own text and proof files (NFO, SFV, DIZ, images).

An .rsr file can't be used to get a game. Without your own matching files it produces nothing.

Releases whose rebuild data would contain any part of the original files are listed only. They have a page with their file list, but no .rsr download.
