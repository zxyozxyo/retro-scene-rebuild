Get the app

Rebuilding a release needs the free RetroVault Toolkit for Windows. It reads the .rsr file, runs the original archiver, and checks every rebuilt volume against the original hashes.

Download from GitHub

The source and the latest version are always at __REPO_SHORT__. On that page click the green Code button, then Download ZIP.

1. Install

  1. Unzip the download anywhere, for example C:\RetroVault.
  2. Double-click Install RetroVault.bat. If Python is missing it offers to install it (free, from python.org). It sets up everything inside that folder and nothing outside it.
  3. Start the app with RetroVault.bat, or the desktop shortcut the installer offers.

Windows 10 or 11. To remove it, delete the folder.

2. Add the archivers

The app needs the same archiver build that made each release. These are other people's programs and are not hosted here. The Tools page lists every build and where they come from.

  1. Collect the RAR installers or executables you can find in one folder, with any names.
  2. In the app open RSR Scanner, then Database → Import from folder…. It recognises each build by its contents and files it under the right name.
  3. Check packers shows what is still missing. A missing build only affects releases made with it; every release page says which one it needs.

3. Rebuild a release

  1. Find the release here and download its .rsr file.
  2. Put your own copies of the release's files in one folder. The release page lists each file with its size and CRC32; the names don't matter, the contents do.
  3. In RSR Scanner, under Rebuild, choose Single. Pick the .rsr file, the folder with your files, and an output folder, then click Rebuild.

The release comes out in the output folder, with its NFO, SFV and other release files. Every volume is checked against the original hashes, and the app tells you plainly if anything doesn't match.
